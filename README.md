## 📖 Overview

Modern Security Operations Centers (SOCs) are overwhelmed by thousands of daily alerts generated by rule-based SIEM systems. This causes **alert fatigue**, delaying response to genuinely critical breaches.

This work presents an **Explainable AI (XAI) framework** that automatically classifies and prioritizes network alerts by fusing:

- **Machine learning probability estimates** (moderated square-root-balanced XGBoost)
- **A NIST SP 800-30-aligned Business Impact Scoring Rubric**

SHAP values are integrated to make the model interpretable for SOC analysts, and a weighted Priority Score `S_P = α·P_threat + (1-α)·I` injects operational business risk into alert ranking.

### Key Results

| Metric | Value |
|---|---|
| Overall Accuracy | **99.64%** |
| Weighted F1 | **1.00** |
| Macro F1 (5-fold CV) | **0.8322 ± 0.0187** |
| Critical Attack Recall (4 rare classes) | **0.94** |
| Top-50 Critical Attack Surface Rate | **100%** |
| Improvement over Random Forest baseline | **+51%** (critical recall) |

**Highlights:**
- **Heartbleed** (rarest attack, 11 samples) is correctly prioritized at **Rank 1**
- **100%** of Critical High-Loss attacks surface within the Top-50 alerts, vs. **0%** under plain probabilistic ranking
- **22× speedup** in business-risk mitigation vs. unweighted ranking
